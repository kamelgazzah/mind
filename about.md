# 🧠 Master Mind

## 🎯 Objectif

Trouver un nombre secret de **5 chiffres uniques**, généré aléatoirement.
## 🧩 Principe du jeu

Chaque tentative te rapproche de la solution grâce à deux indices :

✔ **Bien placé** : chiffre correct et position correcte  
↻ **Mal placé** : chiffre correct mais mauvaise position  

## 🎮 Comment jouer

1. Saisir les 5 chiffres dans les cases
2. Le score se calcule automatiquement
3. Valider avec le bouton ➜
4. Une nouvelle ligne apparaît si le code n’est pas trouvé

## 🧠 Un entraînement à la concentration

Ce jeu n’est pas seulement un divertissement.

Il permet d’entraîner la **logique, la mémoire et surtout la concentration**.

Dans une époque où les réseaux sociaux, les notifications et les contenus superflus fragmentent notre attention, Master Mind propose un retour à une activité simple mais exigeante :

👉 observer  
👉 réfléchir  
👉 déduire  
👉 se concentrer sur une seule tâche  

Chaque partie devient un petit exercice de discipline mentale.



## 🍀 Bonne chance

La solution n’est jamais trouvée dans la précipitation, mais dans l’analyse et la patience.
